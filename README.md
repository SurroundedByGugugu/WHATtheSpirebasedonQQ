# SlaytheSpirebasedonQQ
当你想在 QQ 群里打牌而你有一个程序鸢朋友的时候：  
总之我是那个程序鸢朋友。  
（其实我自己也想夹带私货但不是很想做 mod）

基于 llob 连接 QQ，如果有人摸到这个仓库想接给自己的 bot 使用，记得检查 `main.py` 的 post 和 host；  
如果不连接 QQ，请使用 `test_game_service.py` 运行。  
在文件 `route_template.py` 中想走什么路自己搭（目前随机性还没做得很好，受限于文本显示地图是战争迷雾模式（喂））

**特别预警：**  
该项目含有大量私货文本内容。重点来源是因为我搞 OC，而且成分包括另一个伊甸。  
我说框架都自建了不致敬伊甸猫做一点 zone 的私货我亏大了（虽然目前版本还没有制作到那一部分）。
