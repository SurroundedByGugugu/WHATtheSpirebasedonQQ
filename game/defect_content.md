# 故障机器人内容与试用

本轮已接入单人路线、单人战斗及测试房。合作/PVP使用独立引擎，本轮未接入。

## 开始与调试

角色菜单新增编号 **5：故障机器人**，保留旧角色编号。

```text
/card new 5
/ctrl testroom battle
/ctrl addcard 电击+ 手牌
/ctrl addcard 搜寻+ 手牌
/ctrl addpotion 集中药水
/ctrl orb help
```

正常游玩沿用现有路线、战斗奖励、商店与升级流程。`/ctrl` 用于测试。
搜寻、全息影像与回收会显示候选牌；使用 `/card pick 0` 选择，搜寻+可使用 `/card pick 0 1`。
牌选择编号从0开始，按提示一次提交所需数量；充能球控制指令的位置从1开始。
选择尚未完成时不能继续出牌；回响产生的多次选择按顺序完成。

## 内容范围

- 初始75生命、3能量、99金币、3药水栏和3球槽。
- 初始牌组：打击×4、格挡×4、电击、双重释放；初始遗物为破损核心。
- 75种蓝色牌及升级：4种初始、18种普通、36种罕见、17种稀有；71种进入蓝色奖励卡池。
- 10件专属遗物：新增9件，已有的萝卜（Turnip）改为故障机器人专属。
- 3种专属药水：集中药水（2集中）、扩容药水（2球槽）、黑暗精华（每个球槽生成1个黑暗球）。支持神圣树皮翻倍。
- 卡池、遗物池和药水池沿用角色归属筛选。冰冻核心需持有破损核心才进入对应首领奖励，并在获得时替换破损核心。

## 充能球与本项目规则

沿用已确认的五种球数值、FIFO、集中和Zone规则，详见[充能球规则与控制指令](orbs/README.md)。
混沌仅随机生成原作的闪电、冰霜、黑暗、等离子；玻璃球仍可通过控制指令生成，并参与通用激发、计数、循环等效果。
普通角色默认零球槽，故障机器人每场恢复3个基础球槽，符文电容器再增加3个。

自然结算顺序为手牌结束回合效果与清理 → 中毒 → 非等离子球被动 → 敌人行动。
等离子球在正常恢复能量后结算；循环与情感芯片随后在回合开始事件中触发。
自然被动使用阶段开始时的球快照，阶段中新生成的球不加入当次结算。
球击杀最后一个非爪牙敌人后结束战斗，包括循环等回合开始效果造成的击杀。
冰冻核心在玩家结束回合阶段有空槽时生成冰霜球，因此可进入随后自然被动的快照。

递归保留黑暗计数与玻璃基础值；多重释放/双重释放反复激发同一颗球后仅移除一次。
遗传算法将成长同步回冒险主牌组；爪击、蒸汽护壁与精简改良的战斗内变化保留至本场结束。
自我修复可正常获得，但不进入战斗内随机生成卡池。

原有无色牌 `card.amplify` 保持原内容；蓝色增幅使用 `card.amplify_defect`，蓝色缓冲使用 `card.buffer_defect`。
调试中如中文别名重名，可直接填写上述卡牌ID。
本项目沿用已有的遗物稀有度结构，冰冻核心标为初始遗物升级类 `myth`，并接入首领奖励。
