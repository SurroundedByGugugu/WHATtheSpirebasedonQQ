# 李昼实装说明

## 入口与初始配置

- 单人：`/card new 7`，或 `/card new character.lizhou`。网页角色选择同步提供李昼。
- 多人合作测试房：`/card multi new 7` / `/card multi join 7`。
- 李昼：75 最大生命、99 金币、3 能量、3 药水槽。
- 初始遗物：锚定之眼、十二星座卡牌。
- 已确认初始牌组：4 打击、4 防御、钝气弹、绽放的星之花、调正星位各 1，共 11 张。
- 共 75 张牌：21 攻击、31 技能、23 能力；均有升级版本。其中 5 种初始牌不进奖励池。
- 卡牌和遗物纳入现有私货开关；关闭时从相应随机／奖励／商店池过滤，保持既有角色选择方式。

独立 PVP 测试房仍使用自身的延迟攻击／过热规则及原有角色列表，本次没有开放李昼的 PVP 入口。

## 已确认机制

- 调序下限为 0、跨回合保留。先执行基础效果，再检查调序；足够时扣费，再执行附加效果，不足只略过附加效果。
- 无数值的锚定／浮动为 1 层。单张牌一次获得任意正层数只触发一次事件；多张牌分别计次。
- 锚定和浮动为实体牌的战斗内状态，跨抽牌／弃牌／消耗牌堆保留。复制继承全部状态及首次打出、回合内次数等记录。
- 手动打出受浮动及固定门槛限制；自动打出绕过浮动、锚定和固定调序门槛，不支付锚定门槛。自动打出不自动豁免调序附加效果的费用；明确“免费”的来源则同时免能量和调序并绕过调序检查。
- 免费范围：月光、浮游之星、释放流星雨、领域展开。双子座只免能量，按当前牌调序消耗检查，不足立即停止。
- 领域展开按每张实体牌每回合 1 次，包含之后生成的牌，排除施放领域的本牌。领域效果到下一回合失效，领域自身保留降费持续本场战斗。
- 单独触发星座效果不算打出牌。星尘癌仍可重复这种效果；真正打出的星座牌重复基础和首次检查通过的附加效果，不重复支付，重复算作打出事件。额外触发不占前 N 个名额。
- 星尘癌升级只将能量消耗 3 降到 2；N 份覆盖本回合前 N 个星座效果，每个额外触发 1 次。
- 固强／坚韧／抗衡的层数是回合数：分别造成伤害 +25%、获得格挡 +25%、受到伤害 -50%；多层不增加倍率，回合结束减 1。百分比取整沿用现有引擎向下取整。
- 虚无世界逐段检查原有格挡，无格挡则给予双倍受伤，再清空格挡并攻击。双倍受伤的层数为回合数，倍率固定 2，可被人工制品挡下。
- 绽放的星之花先触发弃牌／消耗事件再返回手牌；手牌已满则留在弃牌堆，等正常洗回和抽取。打出、失去保留时恢复保留。升级首次奖励在清空锚定以后给予，每场战斗一次，复制继承使用记录。
- 双子座从所有区域使用全部星之花，先处理手牌从左到右，再处理消耗牌堆的原始快照；新消耗的牌不重新进入本轮。升级仅获得等量能量，不清零星之花、不触发首次打出。递归双子座复用可暂停结算流程。
- 微小湮灭按获得／消耗调序的点数、获得锚定／浮动的牌张数降费，下限 0；以本次支付时的实际费用记录降费差（包括免费），晕眩全体、伤害单体。
- “消耗调序”按支付附加效果的费用计算；“失去调序”仅扣除资源，不作为支付触发微小湮灭降费。
- 十二星座卡牌仅在长期牌组获得重复星座牌时触发，升级状态参与重复判定；转换可再次得到原星座，保留升级，形成重复时继续提供选择。
- 普通临时修改仅限本场战斗；长期牌组与战斗牌组分离，回到长期牌组时不带回这些修改。

## 回合结束时序（暂定插槽）

用户已明确固定主序列及无限与虚无在弃牌后；其他能力的最终插槽仍待统一讨论。本次采用：

1. 弃牌前插槽：投刃皆虚、幻魔、天文的远见，按战斗内施放顺序执行。幻魔仅在施放当回合有效，同回合多张仅保留首次注册。
2. 锚定之眼：当前手牌拥有保留词条的牌增加 1 锚定。
3. 当前手牌浮动减 1。
4. 对无保留且有锚定的手牌逐张选择是否消耗 1 层保留。选择界面可一次提交多张，各张独立扣层；有保留词条的不扣锚定。
5. 既有回合末手牌清理：虚无优先消耗，其余未保留牌弃置。
6. 弃牌后插槽：无限与虚无对剩余手牌随机一张施加浮动及锚定；新层数留待下回合处理。

能力叠加：调序者独立从 0 计数；四象／仰望分别选择；数值型能力分别触发；月光、浮动潮汐、无限与虚无、虚无世界重复获得无额外效果。额外回合累计，跳过敌方行动，开始及结束事件照常处理。

## 选择命令

- 战斗选择：`/card pick 0 2`；允许选择 0 张时可 `/card skip`。
- 星座遗物：`/card zodiac 0` 或 `/card zodiac skip`。
- 多人选择：`/card multi pick 0 2` 或 `/card multi skip`。
- 网页沿用选择面板；手牌预览显示锚定、浮动、当前调序条件及特殊动态信息。
